# About the project

- **Main focus**: Learn more about connecting to a cloud-hosted database, JPA, and Spring Boot annotations.
- **What is the project?**: It is an order management system comprising products, orders, product categories, payment management, and a customer list.
- **Where does the foundation come from?**: From Professor Nelio Alves Java course hosted on the Udemy platform, Section 22.
- **What was learned?**: In this project, I learned how to handle databases using JPA, H2, PostgreSQL, and Spring Boot, work with various Spring annotations, and connect to external databases (the course used Heroku, a service requiring a subscription, whereas I used Render, an alternative that offers a trial).
