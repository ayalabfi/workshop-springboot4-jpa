- Spring Initializr: Ferramenta web oficial do Spring para iniciar um projeto Spring e adicionar dependências.

- Dependências importantes:
1 - Spring Web: Concentra-se na criação de serviços Web orientados a documentos. O objetivo do Spring Web Services
é facilitar o desenvolvimento de serviços SOAP com abordagem "contrato-primeiro", permitindo a criação de serviços
Web flexívesi utilizando uma das diversas maneiras de manipular payloads XML. O produto é baseado no próprio
Spring, o que significa que você pode usar os conceitos do Spring, como injeção de dependência, como parte integrante do seu
serviço Web;
2 - H2 Database: É um banco de dados utilizado para testes;
3 - Spring Data JPA: Faz o mapeamento objeto-relacional;
4 - PostreSQL Driver: Driver do banco de dados PostreSQL;

- Notations:
1 - @RestController: Indica que a classe é um recurso Web implementado por um controlador Rest;
2 - @RequestMapping: Dá um nome para o recurso;
3 - @GetMapping: Indica que a requisição retorna uma requisição do tipo get do HTTP;
4 - @Configuration: Indica que a classe que possui essa notation é uma classe de configuração;
5 - @Profile("user"): Indica a qual perfil será aplicado a configuração;
6 - @Autowired: Cria uma dependência com o atributo definido abaixo dessa notation e associa
uma instância;
7 - @Component: Registra a classe como componente do Spring;
8 - @Repository: Registra a classe como um repositório;
9 - @Service: Registra a classe como um serviço;
10- @PathVariable: Captura valores da URL e os passa como parâmetros para o método;
11- @ManyToOne: Indica que serão muitos para um, ou seja, faz sentido inserir essa
notation em uma tabela pedidos no atributo que relaciona um cliente;
12- @JoinColumn(name = "chave estrangeira"): Define qual coluna faz a ligação entre as duas
tabelas de um relacionamento;
13- @ManyToOne(mappedBy = "atribute"): Indica que será um para muitos, ou seja, faz sentido
inserir essa notation em uma tabela cliente no atributo que relaciona os pedidos, o mappedBy
indica qual o atributo na outra tabela faz relação com a tabela de inserção da notation.
14- @JsonIgnore: Faz com que o Json ignore um chamado, isso é usado para evitar loops por
exemplo entre cliente trazendo os dados dos pedidos e os pedidos trazendo os dados do cliente;
15- @Transient: Evita que o JPA tente interpretar;
16- @ManyToMany: Indica que será muitos para muitos, ou seja, faz sentido inserir essa natation
em uma tabela produto no atributo que relaciona categorias, pois um produto pode ter várias
categorias e uma categoria pode ter vários produtos;
17- @JoinTable: Cria uma nova tabela, ideal para quando é necessário fazer uma relação entre 2
tabelas, como no caso onde é necessário criar um @ManyToMany;
18- @Embeddable: Serve para criar um objeto que não vira uma tabela própria, mas pode ser incorporado
dentro de outra entidade, comumente usada para representar grupos de campos relacionados, objetos de valor
e composição de atributos, utilizando o @Embeddable, os campos da classe são "Embutidos" na tabela da
entidade principal.
19- @EmbeddedId: É usada para definir uma chave primária composta usando uma classe incorporável (@Embeddable);



- Implements:
1 - CommandLineRunner: Executo o código automáticamente após a aplicação subir e o contexto
do Spring estar totalmente inicializado;


- Spring Framework Types:
1 - ResponseEntity<Class Type>: É um tipo específico para retornar respostas de requisições Web.
1.1 - .ok: retorna a resposta com sucesso no HTTP;
1.2 - .body(obj): Retorna o corpo da resposta com o objeto indicado;
2 - JpaRepository<Class, TypeId>: Cria um objeto repository do pacote JPA com uma implementação
padrão para o tipo definido;

- Classes de conecimento atual:
1 - Optional<T>: É uma classe utilizada para representar um valor que pode ou não existir,
Serve principalmente para evitar NullPointerException e deixar explícito quando um retorno
pode ser vazio;


- Class para configuração de perfil: classe auxiliar que faz algumas configurações na aplicação.

- ISO 8601: Representação de datas por meio de texto;
1 - Padrão: 2026-05-22T10:47:33Z;
1.1 - Detalhamento: ano-mes-diaT(Time)hora-minuto-segundoZ(Indica que o horário está em
UTC (Tempo universal coordenado))

- Quando você tem uma associação para muitos, o JPA não carrega essa associação para muitos,
isso acontece para não estourar a memória e o trafego do computador, fazendo o Lazy Loading,
ou seja, apenas se você acionar os objetos do lado para muitos.

- Set e HashSet: São usados para armazenar coleções de elementos sem permitir duplicatas.
